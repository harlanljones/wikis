# Example Wiki

Welcome. This wiki is one app in the monorepo, served by its own Bun server.

Every markdown file in `content/` is a page. This page is `content/index.md`.

## Where to go next

- [[Getting Started]] covers running the wiki and adding pages.
- [[Guides]] shows how nested pages work.
- [[A Page That Does Not Exist]] shows how a link to a missing page looks.
