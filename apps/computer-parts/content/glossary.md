# Glossary

Short definitions of the terms used in this wiki and on product listings. Each entry links to the page that explains it properly.

## Numbers

### 1% low
The frame rate during the slowest one percent of a test. A measure of stutter. See [[specs/benchmarks|Reading benchmarks and reviews]].

### 1080p, 1440p, 4K
Screen resolutions: 1920 x 1080, 2560 x 1440 and 3840 x 2160 pixels. See [[parts/monitor#Size and resolution|Size and resolution]].

### 12V-2x6
The compact power connector on most current Nvidia graphics cards, carrying up to 600W. It replaced 12VHPWR. See [[parts/power-supply#Connectors|Connectors]].

### 80 Plus
An efficiency rating for power supplies: Bronze, Gold, Platinum, Titanium. See [[parts/power-supply#Efficiency rating (80 Plus)|Efficiency rating]].

## A

### AIO
All-in-one liquid cooler: a sealed pump, tubes and radiator. See [[parts/cooling|Cooling]].

### AM4, AM5
AMD's desktop processor sockets. AM5 is current. See [[parts/motherboard|Motherboard]].

### Arm
A processor architecture used by Apple's M-series and Qualcomm's Snapdragon chips, as opposed to the x86 architecture of Intel and AMD. See [[buying/laptops#Windows on Arm|Windows on Arm]].

### Aspect ratio
The shape of a screen. 16:9 is standard widescreen, 16:10 is slightly taller, 21:9 is ultrawide.

### ATX
The standard desktop motherboard size, and also the standard for power supplies. See [[parts/motherboard#Form factor|Form factor]].

## B

### Benchmark
A repeatable test used to compare hardware. See [[specs/benchmarks|Reading benchmarks and reviews]].

### BIOS
The motherboard's built-in setup software, reached by pressing Delete or F2 at startup. Also called UEFI. See [[building/assembly#First boot|First boot]].

### Bottleneck
The part limiting overall performance. See [[basics#Balance and bottlenecks|Balance and bottlenecks]].

### Burn-in
Permanent faint ghosting on an OLED screen from static images shown for very long periods. See [[parts/monitor|Monitor]].

## C

### Cache
A small amount of very fast memory inside a processor. Also a fast buffer on an SSD. See [[parts/cpu#Cache, and what X3D means|Cache]].

### CAS latency (CL)
The first memory timing number. Lower is quicker at the same speed. See [[parts/memory#Timings (CL)|Timings]].

### Chipset
The motherboard's feature tier, such as B850 or Z890. See [[parts/motherboard#Chipset|Chipset]].

### Clock speed
How many cycles per second a processor core runs, in GHz. See [[parts/cpu#Clock speed (GHz)|Clock speed]].

### CMR and SMR
Two hard drive recording methods. CMR is preferred for a NAS. See [[parts/storage#Hard drive specs|Hard drive specs]].

### Copilot+ PC
Microsoft's label for Windows laptops with an NPU of 40 TOPS or more, 16GB of memory and 256GB of storage. See [[specs/marketing-terms|Marketing terms to ignore]].

### Core
One independent processing unit inside a processor. See [[parts/cpu#Cores and threads|Cores and threads]].

### CPU
Central processing unit: the processor. See [[parts/cpu|Processor]].

### CUDA
Nvidia's software platform for using graphics cards for general computing. Most AI and much rendering software depends on it.

## D

### DDR4, DDR5
Generations of memory. They are not interchangeable. See [[parts/memory#Type (DDR4, DDR5)|Type]].

### Delta E (ΔE)
A measure of color error. Under 2 is invisible to the eye.

### DIMM
A desktop memory stick. The laptop version is SO-DIMM. See [[parts/memory#Form factor|Form factor]].

### DisplayPort
A video connection, the default for PC monitors. See [[specs/ports-and-cables#DisplayPort|DisplayPort]].

### DLSS
Nvidia's upscaling and frame generation technology. See [[parts/gpu#Upscaling and frame generation (DLSS, FSR, XeSS)|Upscaling]].

### DPI
Mouse sensitivity in dots per inch. See [[parts/peripherals#Sensor and DPI|Sensor and DPI]].

### DSC
Display Stream Compression: visually lossless compression that lets a cable carry higher resolutions and refresh rates.

### Dual channel
Running two memory sticks together for double the bandwidth. See [[parts/memory#Kit size (2x16GB)|Kit size]].

## E

### ECC
Error-correcting memory, used in servers. See [[use-cases/home-server|Home server and NAS]].

### E-core
An efficiency core: a smaller, slower, low-power processor core. See [[parts/cpu#Performance cores and efficiency cores|Core types]].

### eMMC
Slow, soldered flash storage found in the cheapest laptops. Avoid for a main computer.

### Ethernet
Wired networking. See [[parts/networking|Networking]].

### EXPO
AMD's name for a memory speed profile. See XMP.

## F

### Form factor
The standard size and shape of a part: ATX for motherboards, 2280 for M.2 drives, and so on.

### fps
Frames per second: how many images a game draws each second.

### Frame generation
Inserting AI-generated frames between real ones to smooth motion. See [[parts/gpu#Upscaling and frame generation (DLSS, FSR, XeSS)|Frame generation]].

### FreeSync
AMD's name for variable refresh rate. See VRR.

### FSR
AMD's upscaling and frame generation technology.

## G

### GB, TB
Gigabyte and terabyte: units of capacity. 1TB is about 1,000GB.

### GHz
Gigahertz: the unit of processor clock speed.

### GPU
Graphics processing unit. Used for both the chip and the whole graphics card. See [[parts/gpu|Graphics card]].

### G-Sync
Nvidia's name for variable refresh rate. See VRR.

## H

### HDD
Hard disk drive: storage on spinning platters. See [[parts/storage|Storage]].

### HDMI
A video connection, the default for TVs and consoles. See [[specs/ports-and-cables#HDMI|HDMI]].

### HDR
High dynamic range: brighter highlights and deeper shadows. See [[parts/monitor#HDR|HDR]].

### Heat sink
A block of metal fins that carries heat away from a part.

### Hz
Hertz: times per second. Used for screen refresh rate.

## I

### iGPU
Integrated graphics: a graphics chip built into the processor. See [[parts/cpu#Integrated graphics|Integrated graphics]].

### IPC
Instructions per cycle: how much work a processor does in each clock cycle.

### IPS
A common LCD panel type with good color and viewing angles. See [[parts/monitor#Panel type|Panel type]].

### ITX
Mini-ITX: the smallest common motherboard size.

## L

### Latency
Delay. In memory, in networks, and between a click and the screen responding.

### LGA 1700, LGA 1851
Intel's previous and current desktop sockets.

### LPDDR
Low-power memory soldered into laptops. Not upgradable.

## M

### M.2
A small slot for SSDs and Wi-Fi cards. See [[parts/storage#Interface: NVMe, SATA|Interface]].

### Mbps, Gbps
Megabits and gigabits per second: units of network and cable speed. Eight megabits make one megabyte.

### Mini-LED
A backlight with thousands of small LEDs in dimmable zones, for better contrast and HDR. See [[parts/monitor#Panel type|Panel type]].

### Modular
A power supply with detachable cables. See [[parts/power-supply#Modularity|Modularity]].

### Motherboard
The main circuit board. See [[parts/motherboard|Motherboard]].

### MSRP
The manufacturer's suggested retail price. The launch price, as opposed to the street price you actually pay.

## N

### NAS
Network-attached storage: a small file server. See [[use-cases/home-server|Home server and NAS]].

### Nits
A unit of screen brightness.

### NPU
Neural processing unit: a chip for small on-device AI tasks. See [[parts/cpu#Specs you can mostly ignore|Processor]].

### NVMe
The fast protocol used by modern SSDs. See [[parts/storage#Interface: NVMe, SATA|Interface]].

## O

### OLED
A screen type where each pixel makes its own light, giving perfect blacks. See [[parts/monitor#Panel type|Panel type]].

### Overclocking
Running a part faster than its rated speed. Rarely worthwhile on current hardware.

## P

### P-core
A performance core: a full-size, fast processor core.

### PCIe
The high-speed connection used by graphics cards and NVMe SSDs. Versions are 3.0, 4.0 and 5.0, each twice as fast as the last.

### Polling rate
How often a mouse or keyboard reports to the computer, in Hz.

### Power Delivery (PD)
The USB-C charging standard. See [[specs/ports-and-cables#Charging over USB-C|Charging over USB-C]].

### PPI
Pixels per inch: the sharpness of a screen.

### PSU
Power supply unit. See [[parts/power-supply|Power supply]].

### PWM
A way of controlling fan speed smoothly, using 4-pin fans.

## Q

### QLC and TLC
Types of SSD flash storing four and three bits per cell. See [[parts/storage#Going deeper|Storage]].

### Quantization
Compressing an AI model so it needs less memory. See [[use-cases/local-ai|Running AI models locally]].

## R

### RAID
Combining several drives for redundancy or speed. Not a backup. See [[use-cases/home-server#Redundancy|Redundancy]].

### RAM
Random access memory: the computer's working space. See [[parts/memory|Memory]].

### Ray tracing
Realistic lighting simulation in games. See [[parts/gpu#Ray tracing|Ray tracing]].

### Refresh rate
How many times per second a screen updates, in Hz. See [[parts/monitor#Refresh rate (Hz)|Refresh rate]].

### Resolution
The number of pixels on a screen.

### Response time
How quickly a pixel changes color. See [[parts/monitor#Response time|Response time]].

### RGB
Colored lighting. Decorative only.

## S

### SATA
An older, slower connection for drives. See [[parts/storage#Interface: NVMe, SATA|Interface]].

### SFF
Small form factor: a very compact PC.

### Socket
The connector on a motherboard that holds the processor. See [[parts/cpu#Socket|Socket]].

### SO-DIMM
A laptop-size memory stick.

### Soldered
Permanently attached to the board, and so not replaceable or upgradable.

### sRGB, DCI-P3, Adobe RGB
Color ranges used to describe how much color a screen can show. See [[parts/monitor#Color gamut and accuracy|Color gamut and accuracy]].

### SSD
Solid-state drive: fast storage with no moving parts. See [[parts/storage|Storage]].

## T

### TBW
Terabytes written: an SSD's rated endurance.

### TDP
Thermal design power: a rough indicator of a processor's heat output. See [[parts/cpu#Power draw and TDP|Power draw and TDP]].

### TGP
Total graphics power: the wattage a laptop gives its graphics chip. See [[specs/gpu-model-names#Laptop graphics|Laptop graphics]].

### Thermal paste
A compound that fills the gap between a processor and its cooler.

### Thermal throttling
A part slowing itself down to avoid overheating.

### Thread
A sequence of work a processor core can run. Some cores run two at once.

### Thunderbolt
A certification for USB-C ports that guarantees high speed, video and charging. See [[specs/ports-and-cables#Thunderbolt|Thunderbolt]].

### TOPS
Trillions of operations per second: a rating for NPUs.

### TPM
Trusted Platform Module: a security chip that Windows 11 requires.

## U

### Unified memory
Apple's term for memory shared between the processor and graphics.

### Upscaling
Rendering a game at lower resolution and reconstructing a sharper image. See [[parts/gpu#Upscaling and frame generation (DLSS, FSR, XeSS)|Upscaling]].

### UPS
Uninterruptible power supply: a battery backup that covers short power cuts.

### USB-C
A small reversible connector. It describes the plug shape only, not the speed or features. See [[specs/ports-and-cables#USB|USB]].

### USB4
A USB standard offering 20Gbps to 80Gbps over USB-C.

## V

### VA
An LCD panel type with high contrast. See [[parts/monitor#Panel type|Panel type]].

### VESA mount
The standard screw pattern on the back of a monitor for arms and wall mounts.

### VRAM
A graphics card's own memory. See [[parts/gpu#VRAM (graphics memory)|VRAM]].

### VRM
Voltage regulator module: the motherboard circuitry that powers the processor. See [[parts/motherboard#Power delivery (VRM)|Power delivery]].

### VRR
Variable refresh rate: matching the screen's updates to the graphics card's output. See [[parts/monitor#Adaptive sync (G-Sync, FreeSync, VRR)|Adaptive sync]].

## W

### Wh
Watt-hours: the unit of battery capacity.

### Wi-Fi 6, 6E, 7
Wi-Fi generations. See [[parts/networking#Wi-Fi generation|Wi-Fi generation]].

## X

### X3D
AMD processors with extra cache for gaming. See [[parts/cpu#Cache, and what X3D means|What X3D means]].

### x86
The processor architecture used by Intel and AMD.

### XeSS
Intel's upscaling technology.

### XMP
Intel's name for a memory speed profile that must be enabled in the BIOS. AMD's equivalent is EXPO. See [[parts/memory#XMP and EXPO|XMP and EXPO]].
