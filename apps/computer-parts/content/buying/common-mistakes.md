# Common mistakes

> **In one sentence:** most wasted money goes on the wrong part for the job, on big numbers that do not matter, or on forgetting something small that stops everything working.

A checklist to read before paying. Each item links to the page that explains it.

## Buying the wrong thing for the job

- **Buying a graphics card you will never use.** Office work, web browsing and streaming need none. See [[parts/gpu|Graphics card]].
- **Spending on the processor and skimping on the graphics card for a gaming PC.** Games depend mostly on the graphics card. See [[use-cases/gaming|Gaming]].
- **Buying a gaming laptop that will never leave the desk.** A desktop gives more for less. See [[buying/desktop-or-laptop|Desktop or laptop?]].
- **Buying 64GB of memory for gaming**, or 8GB for video editing. See [[parts/memory|Memory]].
- **Neglecting the monitor.** A fast PC on a poor screen looks like a slow PC. See [[parts/monitor|Monitor]].
- **Paying a large premium for "future proofing".** See [[specs/marketing-terms#About "future-proofing"|About future-proofing]].

## Trusting the wrong numbers

- **Choosing a processor by its tier name.** "Core i7" without a model number can be years old. See [[specs/cpu-model-names|Processor model names]].
- **Comparing gigahertz across brands or generations.** See [[parts/cpu#Clock speed (GHz)|Clock speed]].
- **Comparing core counts across brands.** See [[parts/cpu#Performance cores and efficiency cores|Core types]].
- **Choosing a graphics card by VRAM alone.** See [[parts/gpu#VRAM (graphics memory)|VRAM]].
- **Believing "1ms" and "HDR" on a monitor box.** See [[specs/marketing-terms|Marketing terms to ignore]].
- **Assuming a laptop graphics chip equals the desktop card of the same name.** See [[specs/gpu-model-names#Laptop graphics|Laptop graphics]].
- **Paying for SSD speed you cannot feel** instead of capacity you will use. See [[parts/storage|Storage]].

## Laptop mistakes

- **Not checking whether memory and storage are soldered.**
- **Buying 8GB of soldered memory in a Windows laptop** meant to last five years.
- **Ignoring the screen's brightness and color coverage** because the listing left them out.
- **Believing the advertised battery life.**
- **Buying a Windows on Arm laptop without checking that your software and games run on it.** See [[buying/laptops#Windows on Arm|Windows on Arm]].
- **Assuming every USB-C port charges and drives a display.** See [[specs/ports-and-cables|Ports and cables]].
- **Buying a Chromebook close to its update expiry date.**

See [[buying/laptops|How to choose a laptop]].

## Prebuilt mistakes

- **Not checking the power supply brand.**
- **Accepting one stick of memory** where there should be two.
- **Buying a tower with proprietary parts** and expecting to upgrade it.
- **Choosing a sealed glass-front case** that overheats.
- **Not comparing the price against the parts.**

See [[buying/prebuilt-desktops|How to choose a prebuilt desktop]].

## Build mistakes

Compatibility:

- **Processor and motherboard with different sockets.**
- **DDR4 memory for a DDR5 board**, or the reverse.
- **A graphics card too long for the case**, or a cooler too tall.
- **A power supply without the right connectors** or enough wattage.
- **A processor with no integrated graphics and no graphics card.**
- **A motherboard that needs a BIOS update** to recognise a new processor.

See [[building/compatibility|Compatibility checklist]].

Assembly and setup:

- **Plugging the monitor into the motherboard** instead of the graphics card.
- **Never enabling XMP or EXPO**, so the memory runs slowly.
- **Leaving the monitor at 60Hz** in Windows.
- **Memory in the wrong pair of slots.**
- **Leaving the plastic film on the cooler.**
- **Mixing modular cables between power supplies.** This one destroys hardware.
- **Forgetting the power supply's own switch.**

See [[building/assembly|Putting it together]].

## Shopping mistakes

- **Buying on the day you first look.** Sleep on it and read one review.
- **Trusting a crossed-out price.** Check the price history.
- **Buying an extended warranty by reflex.**
- **Buying from a marketplace seller with no history** to save a few dollars.
- **Throwing away the box** before the return window closes.
- **Not testing hard inside the return window.**
- **Waiting indefinitely for the next generation.** See [[buying/when-to-buy|When to buy]].

## Ownership mistakes

- **No backup.** Every drive fails eventually. See [[parts/storage#Backups|Backups]].
- **Never cleaning the dust out.** See [[parts/cooling|Cooling]].
- **Replacing a slow computer that only needed an SSD or a clean reinstall.** See [[buying/upgrading|Upgrade or replace?]].
- **Blaming the computer for bad Wi-Fi.** See [[parts/networking|Networking]].
- **Running a laptop on a bed or sofa** that blocks its vents.
- **Skipping updates** for the operating system, graphics driver and motherboard BIOS when something is misbehaving.

## The five-question check

Before buying anything, answer these:

1. **What is the most demanding thing I will do with it?**
2. **Which part does that depend on, and is most of my money going there?**
3. **What cannot be changed later, and is that part good enough?**
4. **Have I read one independent review of this exact model?**
5. **Can I return it?**
